# Random Meme App 

Кроссплатформенное приложение для просмотра случайных мемов с возможностью добавлять в избранное.

## Функционал

- Загрузка случайных мемов из API
- Добавление мемов в избранное 
- Просмотр избранных мемов
- Сохранение данных на устройстве

## Технологии

- Flutter (кроссплатформенная разработка)
- Dart
- REST API (imgflip.com)
- Shared Preferences (локальное хранение)
